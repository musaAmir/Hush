# Hush

A lightweight Mac menu bar app that dims distractions around your active window.

**[Download for macOS](https://github.com/musaAmir/Hush/releases/tag/v0.2.1)** · macOS 14+ · Apple silicon & Intel

Adjust dimming and fades, record keyboard shortcuts, pause temporarily, or exclude specific apps. Everything stays on your Mac.

Unzip the download, move **Hush.app** to Applications, and enable it in **System Settings → Privacy & Security → Accessibility**. Customize it from **Hush → Settings…**. The default toggle is **Control–Option–D**.

This is an early preview: ad-hoc signed, not notarized, and macOS may block opening it. Automatic updates are not configured yet.

Build: `./build.sh universal` · Test: `swift test` · [Testing notes](docs/testing.md)
